# Tugas Bab 01 — Hello World

Kerjakan dari atas ke bawah. Coba sendiri dulu, baru cek jawaban.

## Tingkat Dasar

### Tugas 1 — Sapaan Pribadi
Buat program yang mencetak 3 baris:

```
Halo, nama saya <namamu>
Saya sedang belajar Go
Semoga lancar!
```

### Tugas 2 — Bedakan Print vs Println vs Printf
Tulis program yang mencetak:

```
A B
C
```

- Baris pertama (`A` dan `B`) harus memakai `Print` agar tetap satu baris.
- Gunakan `Println` untuk pindah ke baris berikutnya.

### Tugas 3 — Format dengan Printf
Gunakan `Printf` untuk mencetak satu baris berisi nama, umur, dan kota:

```
Saya <nama>, umur <umur> tahun, tinggal di <kota>.
```

## Tingkat Menengah

### Tugas 4 — ASCII Art Sederhana
Cetak bentuk persegi `3x3` menggunakan karakter `*` (boleh memakai beberapa
`Println`):

```
***
***
***
```

### Tugas 5 — Escape Sequence
Cetak kalimat yang mengandung tanda kutip ganda dan tab:

```
Dia berkata "Belajar Go itu seru!"
Kolom1	Kolom2
```

## Tingkat Mahir

### Tugas 6 — Refleksi
Tanpa melihat materi, jelaskan (tulis di komentar kode) fungsi dari:
`package main`, `import`, dan `func main`.

## Kriteria Selesai

- [ ] Semua program bisa dijalankan dengan `go run ./01-hello-world` (atau file barumu).
- [ ] Output sesuai yang diminta.
- [ ] Kamu bisa menjelaskan beda `Print`, `Println`, dan `Printf`.

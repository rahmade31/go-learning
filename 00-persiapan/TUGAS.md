# Tugas Bab 00 — Persiapan

Bab ini tidak berisi coding, tapi ada beberapa tugas persiapan yang **wajib**
selesai sebelum lanjut ke bab 01.

## Checklist Persiapan

Centang setiap poin setelah selesai:

- [ ] **Go terinstal.** Buka terminal, jalankan `go version`, dan pastikan muncul
      versi (misal `go version go1.22.x ...`).
- [ ] **Editor siap.** VS Code (atau editor lain) sudah terpasang, lengkap dengan
      ekstensi Go.
- [ ] **Struktur repo dipahami.** Kamu tahu fungsi file `go.mod` dan bahwa setiap
      bab ada di folder sendiri.
- [ ] **Perintah dasar dihafal.** Kamu bisa menyebutkan fungsi dari:
      `go run`, `go build`, `go fmt`, `go vet`, `go test`.

## Tugas Praktik

1. Jalankan `go version` dan salin hasilnya ke catatanmu.
2. Dari folder utama `learning-go`, jalankan perintah berikut dan amati hasilnya:

   ```bash
   go run ./01-hello-world
   ```

   Jika keluar `Hello, World!`, berarti instalasi & struktur sudah benar.

## Kriteria Selesai

- [ ] `go version` menampilkan versi Go.
- [ ] `go run ./01-hello-world` berhasil mencetak `Hello, World!`.

Kalau dua hal di atas sudah terpenuhi, kamu siap lanjut ke **[Bab 01](../01-hello-world)**. 🎉
